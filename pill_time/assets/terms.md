# Termos de Uso – Pill Time

**Última atualização:** 23 de junho de 2026
**Elaborado por:** Filipe S. Kaizer

Ao utilizar o aplicativo **Pill Time**, o usuário concorda com os presentes Termos de Uso.

---

# 1. Sobre o aplicativo

O Pill Time é um aplicativo desenvolvido para auxiliar usuários no gerenciamento de medicamentos, horários de administração, lembretes, registros de consumo e acompanhamento do progresso relacionado ao tratamento medicamentoso.

O aplicativo possui finalidade exclusivamente informativa e organizacional, não substituindo orientação médica, farmacêutica ou qualquer acompanhamento profissional de saúde.

O uso do aplicativo é de inteira responsabilidade do usuário.

---

# 2. Limitações médicas

O Pill Time não fornece diagnósticos, prescrições, recomendações médicas ou farmacêuticas.

As informações apresentadas pelo aplicativo possuem caráter meramente informativo e não devem ser utilizadas como única base para decisões relacionadas à saúde.

Em caso de dúvidas sobre medicamentos, doses, horários ou efeitos adversos, consulte um profissional de saúde qualificado.

---

# 3. Cadastro de medicamentos e lembretes

O usuário é responsável por:

- Inserir corretamente os dados dos medicamentos;
- Configurar adequadamente horários e doses;
- Conferir as informações cadastradas;
- Manter o dispositivo configurado para permitir notificações.

Embora o aplicativo utilize mecanismos de lembrete, não é garantido que todas as notificações sejam entregues em todos os dispositivos ou sistemas operacionais.

Falhas de notificação podem ocorrer devido a:

- Configurações de economia de bateria;
- Restrições do sistema operacional (principalmente no *Android*);
- Falhas de conectividade;
- Atualizações do dispositivo;
- Problemas externos fora do controle do desenvolvedor.

---

# 4. Coleta e uso de dados

O Pill Time foi desenvolvido com foco na privacidade dos usuários.

## 4.1 Dados pessoais

O aplicativo não coleta, vende ou compartilha dados pessoais dos usuários para fins comerciais.

Nenhuma informação de identificação pessoal é exigida para o funcionamento básico da aplicação.

## 4.2 Dados de uso e métricas

O aplicativo poderá coletar informações anônimas e agregadas relacionadas ao seu funcionamento, exclusivamente para fins de:

- Correção de erros;
- Monitoramento de desempenho;
- Estatísticas de utilização;
- Melhorias futuras do aplicativo.

Essas informações não têm o objetivo de identificar individualmente qualquer usuário.

---

# 5. Armazenamento de progresso

Os dados de progresso do usuário, incluindo histórico de utilização, pontuação, estatísticas de consumo e demais informações relacionadas ao acompanhamento pessoal, permanecem armazenados localmente no dispositivo.

Esses dados:

- Não são enviados para servidores do desenvolvedor;
- Não são compartilhados com terceiros;
- Não são utilizados para criação de perfis de usuários.

O usuário é responsável pela preservação desses dados em seu próprio dispositivo.

A desinstalação do aplicativo, limpeza dos dados locais ou falhas no dispositivo podem resultar na perda dessas informações.

---

# 6. Imagens enviadas pelos usuários

O aplicativo permite o envio de imagens relacionadas aos medicamentos cadastrados.

Ao enviar uma imagem, o usuário declara possuir os direitos necessários para seu envio e utilização.

As imagens enviadas poderão ser armazenadas em servidores vinculados ao projeto com o objetivo de:

- Associar imagens aos medicamentos cadastrados;
- Melhorar a experiência dos usuários;
- Disponibilizar imagens para futuras consultas realizadas por outros usuários do aplicativo;
- Treinar algoritmos de validação de imagem.

Ao realizar o envio, o usuário concede ao projeto Pill Time uma licença gratuita, não exclusiva e por prazo indeterminado para armazenamento e utilização da imagem dentro das funcionalidades do aplicativo.

O usuário não deve enviar:

- Imagens contendo informações pessoais sensíveis;
- Fotografias de documentos;
- Conteúdo protegido por direitos autorais sem autorização;
- Conteúdo ilegal ou ofensivo.

O desenvolvedor reserva-se o direito de remover imagens inadequadas a qualquer momento.
